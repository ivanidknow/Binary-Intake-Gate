# Binary Intake Gate

> **Автоматизированный «таможенный контроль» для бинарных артефактов в CI/CD и релизах. Превращает сложный технический аудит вендорского и Open Source ПО в понятный вердикт безопасности.**

Binary Intake Gate — это единая точка проверки бинарных файлов (PE, ELF, MSI) и архивов перед их допуском в инфраструктуру. Инструмент за 60 секунд выявляет 85+ техник MITRE ATT&CK, оценивает качество «закалки» (Hardening) и находит скрытые аномалии поведения.

---

## Основные возможности
* **Глубокий Hardening:** Проверка ASLR, DEP, CFG, Intel CET и ACG для предотвращения эксплуатации уязвимостей памяти.
* **Анализ аномалий:** Детекция скрытых механизмов перехвата функций (LD_PRELOAD), высокой энтропии и признаков обфускации.
* **SCA & SAST:** Автоматический поиск CVE в зависимостях и сканирование бинарного кода на CWE-дефекты.
* **Smart Verdict:** Гибкие политики (Dev/Prod) и отчеты в форматах Markdown (RU), JSON и SARIF.
